# Contributing / 贡献

Use a separate branch and small Draft PR. Preserve existing functions, CLI options, tests and compatibility behavior. Run both README suites with UTF-8; report OS/Python, commands and exits. New tests must catch an observable failure. Keep English/Chinese docs aligned, update CHANGELOG, and clearly distinguish fixtures, offline tests and real model execution. A maintainer must review model costs and external actions before running them.

独立分支、小范围 Draft PR；保留函数、CLI 参数、原测试和兼容行为。以 UTF-8 跑两套测试，报告系统/Python、命令和退出码。新增测试需捕获可观察故障。双语同步并更新日志，明确区分测试替身、离线测试和真实模型执行。真实调用费用与外部动作须由维护者先审核。

Supply only material you have rights to distribute. No tokens, raw sessions, private exports or evidence logs. Do not auto-merge, change repository visibility or create a Release. Read SECURITY.md and NOTICE.
仅提交有权分发的内容，不含 Token、原始会话、私人导出和证据日志。不自动合并、改可见性或创建 Release，阅读安全指南和声明。
